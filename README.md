# runbase-test
Runbase MVP disposable test repository: GitHub App, webhook, ruleset, sub-issue, and dependency tests. See runbase#73.

## Quick Start with pnpm

1. **Install pnpm** (if not already installed):
   ```sh
   corepack enable && corepack prepare pnpm@latest --activate
   ```
2. **Initialize a new project**:
   ```sh
   pnpm init
   ```
3. **Install dependencies**:
   ```sh
   pnpm install
   ```
4. **Add a package**:
   ```sh
   pnpm add <package>
   ```
